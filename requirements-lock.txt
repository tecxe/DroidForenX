# DroidForenX build lock - exact pins for reproducible builds.
#
# Installing requirements.txt gives you a range, which means two people
# building the same commit can get different PyQt6 and PyInstaller and end
# up with executables of different sizes. This file removes that freedom.
#
#     python -m pip install -r requirements-lock.txt
#     python build.py
#
# Verified with CPython 3.14.6 on win32. PyInstaller normalises embedded
# timestamps when SOURCE_DATE_EPOCH is set, which build.py does, so the same
# commit on the same Python produces a byte-identical executable.
