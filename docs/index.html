Everything You Need

Professional-grade forensic capabilities packed into a single portable executable.

🔒

Seizure & Isolation

Disable airplane mode, WiFi, Bluetooth, NFC, mobile data and USB in one pass. Chain-of-custody logging for every action.

🔎

Device Identification

Auto-detect device model, Android version, installed packages and storage info over ADB. Works with any Android device with USB debugging enabled.

📥

Data Acquisition

5-stage pipeline: SMS, calls, contacts, social media, deleted files, documents, emails, browser data. Imaging output is selectable - Raw (dd) segments or ZIP - with per-image hashing and verification.

🔍

Examination & Analysis

Run 11 analysis modules over the preserved copy: call logs, SMS/MMS, contacts, browser history, GPS, WiFi, Bluetooth, app artifacts, calendar, deleted data and notes. Read-only — it parses from the acquired copy, never the device.

📄

Court-Ready Reporting

Generate forensic reports in HTML, PDF, JSON, or an XLSX verification workbook that independently re-hashes every artifact. Written in plain English for lawyers and judges.

💻

Zero Installation

Single .exe file. ADB drivers bundled. No Python, no dependencies, no installation wizard. Just double-click and run.

🌙

Dark, Light, or System Theme

The interface opens dark and switches from the View menu — light, or follow the operating system as it changes. Your choice is remembered between launches. Exported reports keep their own fixed palette, so a court document never changes appearance because a UI preference did.

System Requirements

Windows 10 / 11 (64-bit)
USB 2.0+ cable
Android device with USB debugging
~250 MB free disk space, more for acquired data and images
No internet required (offline use)
No root required — app-private data needs root and is reported as such
